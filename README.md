# Blockchain IQ plug-in for Claude

Read-only access to Blockchain IQ research through a remote MCP connector (https://www.blockchainiq.co/api/mcp/free). No account, no API key.

Tools: biq_list_free_dashboards, biq_get_free_dashboard, biq_list_reports, biq_list_research, biq_list_dispatches.

Skills: biq-free-dashboards, biq-research-lookup, biq-dispatch-briefing. Commands: /biq-brief, /biq-dashboards.

Install: `/plugin marketplace add jgmale123/blockchain-iq-claude-plugin` then `/plugin install blockchain-iq@blockchain-iq-marketplace`.

The connector returns indexes and free dashboards only; it never pays, trades or moves funds. Not financial advice. Docs: https://www.blockchainiq.co/connector
